# Yojana Hunter — Frontend (Next.js 14)

Next.js 14 React frontend with TypeScript, Tailwind CSS, and multilingual (i18n) support for Yojana Hunter.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Server runs on [http://localhost:3000](http://localhost:3000).

## Key Pages & Views
* `/` — Landing page with scheme highlights and category portals
* `/interview` — Interactive AI Interview chat with regional language support
* `/schemes` — Scheme catalog with filter, search, and detail modal
* `/profile` — Citizen profile and consent settings
* `/documents` — Document checklist, upload & OCR preview
* `/applications` — Application and affidavit draft review
